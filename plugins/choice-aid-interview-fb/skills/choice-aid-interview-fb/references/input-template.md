# メンバー共有用｜毎回の依頼のしかた

## いちばん簡単な依頼
次の文章に**Gemini面接メモ（できれば逐語録つき）・Indeedレジュメ・手打ち面接メモ**を添える。求職者管理表は、AIが対象者の行だけを読んで補う。

> この面接を「choice aid面接FB」スキルで評価してください。統一評価Ver.1.0で面接官を採点し、良い点・改善点・次回質問のFBを出し、求職者プロファイル44項目・職歴・追加ヒアリング・育成アクションを作って、全CA共通の「中途人材紹介_AI面談FB」に追記し、読み戻して確認してください。未確認の事項は推測で埋めないでください。

テストのときは、テスト環境のFBシートIDとテスト用の管理表IDを依頼文に書く。

## 必要なら足す情報
```text
面接日時：YYYY/MM/DD HH:mm
面接官：
候補者名：
面接企業：
区分：自社採用面接／CA面談／ロープレ
応募職種・求人票：
前回面接での改善課題：
今回の追加手打ちメモ：
管理表照合用の担当CA（同姓同名がある場合）：
面接後の選考結果（分かった場合のみ）：
```

## 資料の役割
- **Geminiメモ／逐語録**：面接官が何を聞き、どう切り返し、何を合意したか（採点の主な材料）
- **Indeedレジュメ**：経歴・日付・雇用形態・職務・資格・スキル
- **手打ちメモ**：補足・聞き取りにくい固有名詞・確認済みの情報。要約と食い違えば要確認として出る
- **求職者管理表**：希望条件・CA備考・提案企業ごとの選考状況（対象者の行だけ。採点には使わない）
- **求人票（あれば）**：企業マッチングの判定（なければ保留）

履歴書・職務経歴書を作りたいときは、別スキル `choice-aid-application-documents` に依頼する。

## 共有前に確認すること
1. 個人情報を扱う社内ルールを理解しているか。
2. FBシートの**編集権限**と、管理表の閲覧権限・接続があるか。
3. スキルが使えない環境なら `prompts/team-paste-prompt.md` を新しい会話の冒頭に貼る。
